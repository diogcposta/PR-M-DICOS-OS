# Prompt 4 — adaptar amostras reais anonimizadas

Só executar quando existirem amostras anonimizadas do Newsoft numa pasta local acordada.

Lê os ficheiros sem os modificar. Inspeciona folhas, cabeçalhos, formatos, estados, datas, moeda, IDs e duplicados. Não mostres nem guardes dados pessoais nos logs ou na resposta.

Antes de implementar:

1. produz um relatório curto por ficheiro;
2. propõe mapeamentos para os contratos canónicos;
3. lista ambiguidades que alteram KPIs;
4. pede confirmação apenas das decisões de negócio realmente necessárias.

Depois da confirmação, cria perfis Newsoft versionados, fixtures anonimizadas mínimas e testes de regressão. Mantém o importador genérico e não introduzas API Newsoft.
